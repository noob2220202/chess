# 밸런스 리포트 (자체 카드 60장, v1)

## 방법
- `engine/src/sim.ts`: 레벨 2 봇(알파베타 2수 + 카드 사용 탐색) 끼리 **미러 드래프트** 480판 (4개 시드 × 120판).
- 카드별 지표: 해당 카드를 보유한 쪽의 점수율(승 1, 무 0.5). 95% 신뢰구간 밖이면 조정 후보.
- 한계: 봇은 ★이 높은 카드를 우선 고르고, 미러라 양쪽이 같은 카드를 고르는 경우가 많아 승률이 0.5 쪽으로 당겨진다. **최종 기준은 레이팅전 실데이터**(`GET /api/cards/stats`, 앱의 "카드 통계" 화면)로 삼는다.

## 결과 요약 (480판)
| 항목 | 값 |
|---|---|
| 백 승 / 흑 승 / 무 | 187 / 129 / 164 |
| 평균 수 | 152.8 (양측 합산) |
| 종료 사유 | 킹 포획 283, 100수 무변화 103, 300수 59, 카드 승리 33, 반복 2 |

- 대부분 카드가 50% ± 10% 안에 분포 → 극단적인 사기 카드는 없음.
- 통계적으로 벗어난 카드: **점멸 73.9% (n=23)**.
- 약세 경향: **무장해제 30% (n=20)**, 폰 폭풍 42.7%, 참호 42.7%.

## 적용한 조정
| 카드 | 변경 | 이유 |
|---|---|---|
| 점멸 | ★2.5 → ★3.5 (드래프트 출현 빈도 감소) | 승률 과다 |
| 무장해제 | 지속 4수 → 6수 | 승률 과소 |
| 대주교 서임 / 재상 임명 | 대가: 폰 제거 → 같은 쪽 나이트 흡수, ★4 → ★3.5 | 실제 플레이에서 h파일이 열려 첫 수부터 재상이 h2를 잡는 문제 발견 |

## 관찰 및 다음 단계
- **선공 이점**: 결판난 판 중 백 59%. 레이팅전은 색을 무작위 배정하고 Glicko-2가 흡수하지만, 실데이터에서도 55%를 넘으면 흑 보정(예: 흑의 첫 드래프트를 4장 중 1장)을 검토.
- **무승부율 34%**는 봇끼리의 소극적 운영 영향이 크다. 실데이터에서 20%를 넘으면 무변화 제한(100수)을 줄이거나 300수 도달 시 판정 규칙(카드 ★ 합이 낮은 쪽 승 등) 도입 검토.
- 시즌마다: 판수 200 이상 & |승률-50%| > 5%p 카드를 ★/효과 조정 후보로 올린다.
